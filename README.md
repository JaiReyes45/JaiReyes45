## How I approach a project

- Keep setup instructions, architecture notes, and evidence close to the code.
- Use models for extraction and suggestions, with deterministic validation and routing.
- Label sample data, illustrative demos, and unfinished acceptance work clearly.
- Build review and recovery paths alongside the happy path.
